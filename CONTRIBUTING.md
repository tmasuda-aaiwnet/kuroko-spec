# 貢献について / Contributing

## 日本語

- 仕様についての質問・意見・誤りの指摘は、**Issue** でお寄せください。歓迎します。
- 仕様書の変更は著者が行うため、**プルリクエストは受け付けていません**。
- 公開の場で扱うのがふさわしくない内容は、https://www.aaiw.net/contact/ からお知らせください。

## English

- Questions, comments and error reports about the specification are welcome as **Issues**.
- **Pull requests are not accepted**, as the specification is edited by the author.
- For matters that should not be discussed in public, please use https://www.aaiw.net/contact/.
